# Full Stack Open - Part 13 (Relational databases)

Blog application backend: Express, Sequelize, Postgres, migrations (Umzug), JWT login with server-side sessions, reading lists.

Environment variables: `DATABASE_URL`, `TEST_DATABASE_URL`, `PORT`, `SECRET`. Run `npm start`; tests: `npm run start:test` in one terminal and `npm test` in another (`TEST_DATABASE_URL` must point to a separate database). `commands.sql` holds the SQL of exercise 13.2 and `cli.js` is the script of exercise 13.3.
